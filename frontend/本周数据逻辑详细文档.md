### 4.3 图表数据生成

**函数**: `generateChartData(transactions, period, params)`
```javascript
const generateChartData = (transactions, period, params = {}) => {
  const { year = new Date().getFullYear(), month = new Date().getMonth() + 1 } = params
  const currentInfo = getCurrentDateInfo()
  
  switch (period) {
    case 'total':
      return generateTotalChartData(transactions)
    case 'year':
      return generateYearChartData(transactions, year, currentInfo)
    case 'month':
      return generateMonthChartData(transactions, year, month, currentInfo)
    case 'week':
      return generateWeekChartData(transactions, year, currentInfo)  // 周度数据生成
    default:
      return generateYearChartData(transactions, year, currentInfo)
  }
}
```

### 4.4 周度图表数据生成核心逻辑

**函数**: `generateWeekChartData(transactions, year, currentInfo)`
```javascript
const generateWeekChartData = (transactions, year, currentInfo) => {
  // 1. 定义周度标签（星期几）
  const weekLabels = ['周一', '周二', '周三', '周四', '周五', '周六', '周日']
  const weekData = []
  const currentWeek = getWeekNumber(new Date())
  
  // 2. 遍历一周的每一天
  for (let dayOfWeek = 1; dayOfWeek <= 7; dayOfWeek++) {
    // 3. 过滤当天的交易记录
    const dayTransactions = transactions.filter(t => {
      const transactionDate = new Date(t.date)
      const transactionDayOfWeek = transactionDate.getDay()
      // 转换星期日(0)为星期日(7)
      const adjustedDayOfWeek = transactionDayOfWeek === 0 ? 7 : transactionDayOfWeek
      const transactionWeek = getWeekNumber(transactionDate)
      
      // 匹配条件：同年 + 同周 + 同星期几
      return transactionDate.getFullYear() === year && 
             transactionWeek === currentWeek && 
             adjustedDayOfWeek === dayOfWeek
    })
    
    // 4. 计算当天汇总数据
    const summary = calculateSummaryFromTransactions(dayTransactions, 'day')
    weekData.push(summary)
  }
  
  // 5. 只显示到当前日期的数据
  const currentDayIndex = currentInfo.dayOfWeek === 0 ? 6 : currentInfo.dayOfWeek - 1
  const filteredWeekLabels = weekLabels.slice(0, currentDayIndex + 1)
  const filteredWeekData = weekData.slice(0, currentDayIndex + 1)
  
  // 6. 创建图表数据集
  return createChartDataset(filteredWeekData, filteredWeekLabels)
}
```

### 4.6 交易汇总计算

**函数**: `calculateSummaryFromTransactions(transactions, period)`
```javascript
export const calculateSummaryFromTransactions = (transactions, period, params = {}) => {
  const income = transactions
    .filter(t => t.type === 'income')
    .reduce((sum, t) => sum + t.amount, 0)
    
  const expense = transactions
    .filter(t => t.type === 'expense')
    .reduce((sum, t) => sum + t.amount, 0)
    
  return {
    totalIncome: income,
    totalExpense: expense,
    netAssets: income - expense,
    transactionCount: transactions.length
  }
}
```

## 6. 数据流转详细步骤

### 6.1 完整数据流

1. **用户点击"本周"**
   - 触发 `onTabChange('week')`
   - 调用 `assetsStore.fetchAssetData('week')`

2. **Store 处理**
   - 设置 `currentPeriod = 'week'`
   - 调用 `assetsApi.getIncomeExpenseTrend({ period: 'week' })`

3. **API 调用**
   - Mock模式：调用 `database_assets.getIncomeExpenseTrend({ period: 'week' })`
   - 生产模式：POST请求到 `/assets/income-expense-trend`

4. **数据库处理**
   - 调用 `generateChartData(transactions, 'week')`
   - 调用 `generateWeekChartData(transactions, year, currentInfo)`

5. **周度数据生成**
   - 获取当前周的所有交易记录
   - 按星期几分组计算汇总
   - 生成标签：`['周一', '周二', ...]`
   - 只显示到当前日期的数据

6. **数据返回**
   - 格式化为API响应格式
   - 返回包含 `day` 和 `month` 字段的数组

7. **Store 更新**
   - 更新 `incomeExpenseTrendData`
   - 触发 `incomeExpenseChartData` getter 重新计算

8. **组件渲染**
   - `updateChartsFromStore()` 更新图表配置
   - Chart.js 重新渲染图表

## 7. 关键问题与修复

### 7.1 已修复的问题

**问题**: Store 的 `incomeExpenseChartData` getter 总是使用 `item.month` 作为标签，导致周度数据显示错误。

**原因**: `getIncomeExpenseTrend` 函数无论什么周期都使用 'month' 作为属性名。

**修复**: 
1. 修改 `getIncomeExpenseTrend` 函数，根据 `period` 动态设置属性名
2. 周度数据使用 'day' 属性，其他周期使用 'month' 属性
3. 保留 'month' 属性以维持向后兼容性

### 7.2 CSS 警告修复

**问题**: `AssetsOverview.vue` 中使用了 `@apply` 指令但项目未安装 Tailwind CSS。

**修复**: 将所有 `@apply` 指令替换为标准 CSS 样式。
