# 页面设计规范文档

## 概述

本文档基于 `OutboundForm.vue` 和 `InboundRecords.vue` 页面的样式分析，提取了关键的页面设计规范，包括布局结构、CSS 样式、组件使用等，用于指导后续页面开发的一致性设计。

**重要说明**: 本设计规范专为 **Web 端** 优化，所有样式和布局均针对桌面浏览器环境设计，不包含移动端适配。

## 技术栈

- **前端框架**: Vue 3 
- **UI 组件库**: Element Plus / Ant Design Vue
- **状态管理**: Pinia
- **样式方案**: SCSS + CSS 变量 + Tailwind CSS 工具类
- **布局系统**: CSS Grid + Flexbox

## 布局结构

### 1. 整体布局

```vue
<template>
  <Layout>
    <div class="page-container">
      <!-- 页面头部 -->
      <div class="page-header">
        <!-- 头部内容 -->
      </div>
      
      <!-- 页面主体内容 -->
      <div class="page-content">
        <!-- 表单或其他内容 -->
      </div>
    </div>
  </Layout>
</template>
```

### 2. 侧边栏组件

**组件路径**: `frontend/src/components/layout`

- **Layout.vue**: 主布局组件
- **Sidebar.vue**: 侧边栏导航组件
- **Header.vue**: 顶部导航组件

**导入方式**:
```javascript

```

## 开发规范

### 1. 命名规范

- **CSS 类名**: 使用 kebab-case (如: `page-header`, `form-section`)
- **组件名**: 使用 PascalCase (如: `Layout`, `Sidebar`)
- **变量名**: 使用 camelCase (如: `formData`, `searchResults`)

### 2. 文件组织

```
frontend/
├── src/
│   ├── components/
│   │   └── layout/          # 布局组件
│   │       ├── Layout.vue
│   │       ├── Sidebar.vue
│   │       └── Header.vue
│   ├── views/               # 页面组件
│   ├── styles/              # 样式文件
│   │   ├── index.scss       # 全局样式
│   │   ├── variables.scss   # 变量定义
│   │   └── components.scss  # 组件样式
│   └── docs/                # 文档目录
└── docs/                    # 项目文档
```

### 3. 响应式设计原则

- **优先**: Web端优先设计
- **断点使用**: 1200px+ (桌面), 1199px以下 (中等屏幕)
- **侧边栏行为**: 
  - 桌面端: 240px 宽度
  - 中等屏幕: 64px 折叠宽度

### 4. 性能优化

- 使用 CSS 变量减少重复代码
- 合理使用 `transition` 提升用户体验
- 避免深层嵌套选择器
- 使用语义化的 HTML 结构

## Web端设计重点

### 1. 布局特点
- **固定侧边栏**: 240px 宽度，支持折叠至 64px
- **大屏优化**: 针对 1200px+ 桌面显示器优化
- **数据密度**: 适合展示大量数据的表格和列表
- **交互丰富**: 支持悬停效果、图片预览、模态框等复杂交互

### 2. 组件设计原则
- **信息密度高**: 在有限空间内展示更多信息
- **操作便捷**: 快捷操作卡片、搜索下拉、批量操作
- **视觉层次**: 通过阴影、边框、颜色区分不同层级
- **数据可视化**: 状态标签、进度条、图表等数据展示

### 3. 特殊组件
- **图片预览**: 大尺寸模态框 (1080x720px)
- **数据表格**: 支持排序、筛选、分页
- **搜索组件**: 实时搜索结果下拉
- **快捷操作**: 语音记账、OCR识别等功能卡片
