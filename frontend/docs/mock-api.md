# Mock API使用说明

## 概述

茶农手账系统在开发阶段提供完整的Mock数据支持，用于模拟真实的API响应和网络延迟。

## 启用Mock模式

### 方法一：UI界面切换
在登录页面找到"Mock模式"开关，点击启用。

### 方法二：手动设置
```javascript
localStorage.setItem('useMock', 'true')
```

### 方法三：自动启用
开发环境下会自动启用Mock模式。

## Mock功能特性

### 认证功能
- ✅ 用户登录/注册
- ✅ 忘记密码/重置密码
- ✅ 验证码发送/验证
- ✅ 用户信息获取
- ✅ 令牌刷新/登出

### 仪表板功能
- ✅ 统计数据（收入、支出、利润、增长率）
- ✅ 收支趋势图（收入绿色、支出红色）
- ✅ 快速操作列表
- ✅ 最近记录列表

### 网络延迟模拟
| 操作 | 延迟时间 |
|------|----------|
| 登录/注册 | 1-1.5秒 |
| 验证码操作 | 0.8-1秒 |
| 仪表板数据 | 0.6-0.8秒 |

## 验证码功能

发送验证码后，在浏览器控制台查看：
```
[Mock] 验证码已发送到 farmer001@example.com: 123456
```

## 开发调试

### 查看Mock状态
```javascript
localStorage.getItem('useMock') === 'true'
```

### 切换Mock模式
```javascript
localStorage.setItem('useMock', 'true/false')
window.location.reload()
```

## 注意事项

1. **仅开发环境有效**：Mock模式只在开发环境下可用
2. **数据不持久**：页面刷新后Mock数据会重置
3. **网络模拟**：所有API调用都有模拟的网络延迟
4. **错误处理**：包含完整的错误处理逻辑

## 故障排除

### 常见问题
- Mock模式无法启用：检查是否在开发环境
- 登录失败：确认使用正确的测试账号
- 验证码问题：检查控制台输出的验证码
- Dashboard数据不显示：确认已成功登录
