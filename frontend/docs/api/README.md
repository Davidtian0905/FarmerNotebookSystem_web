## Mock数据支持

### 概述
系统在开发阶段提供了完整的Mock数据支持，可以在没有后端服务的情况下进行前端功能测试。

### Mock模式启用
1. **UI切换**：在登录页面找到"Mock模式"开关
2. **手动设置**：在浏览器控制台执行 `localStorage.setItem('useMock', 'true')`
3. **默认启用**：开发环境首次访问时自动启用Mock模式

## 通用规范

### 请求格式
- 所有请求使用JSON格式
- 请求头必须包含`auth`字段（值为token）
- 默认请求方式为POST
- 即使参数为空，也需要传递`{}`

### 响应格式
```json
{
  "error": 0,
  "body": {},
  "message": ""
}
```

### 错误码
- `0`: 成功
- `401`: 未授权，需要登录
- `500`: 系统异常
- 其他: 业务异常

### Mock响应处理
Mock模式下，所有API都会返回统一的响应格式，包含模拟的网络延迟和完整的错误处理。
